Privacy Policy

Last updated: November 1, 2026

autopost is a personal publishing tool. It is used only by its developer to post their own videos to their own channels.

Data the app accesses

  • YouTube (YouTube API Services): permission to upload videos, set thumbnails and read basic channel information for the developer's own channels.
  • Google Calendar: permission to create events on the developer's own calendar to report posting results.
  • Instagram and TikTok: permission to publish videos to the developer's own accounts.

How data is used and stored

Access tokens are stored only on the developer's own computer. No data is sent to any server operated by the app, and no data is sold or shared with third parties. The app does not collect information about viewers or other users.

autopost's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

autopost uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google security settings. Deleting the token files on the developer's computer removes all stored data.
